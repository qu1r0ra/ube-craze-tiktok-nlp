# CJ Research Findings - Editor Guide

This guide is written for the editor working in Google Drive. It does not require opening the repository or navigating code folders.

The Drive folder is:

```text

```

The script uses the same relative paths beginning with `editor guide/`. In Drive, open the matching folder and use the files named in the shot list below.

## What this section should feel like

Keep the tone calm, curious, and documentary-like. CJ is explaining what the comments show, not arguing with individual commenters. The main idea is:

> Global appreciation for ube is real, but meaningful appreciation requires cultural accuracy, recognition, and responsibility.

Use one readable primary comment first, then add two to four supporting comments as short layered cut-ins. If the narration has another few seconds, switch from `must_show.pdf` to `supporting.pdf` in the same folder and add up to five more options. The editor does not need to show every comment.

## Sentiment chart instructions

Use `editor guide/02_sentiment/sentiment_distribution.png` during the sentence containing:

- **35.8% neutral**
- **33.8% negative**
- **30.4% positive**

Recommended treatment:

1. Begin with the full chart so the viewer understands the shape.
2. Highlight each segment as CJ names it.
3. Add `6,137 analyzed comments` in a small caption.
4. Add a small note: `Model classifications; not a survey of all Filipinos.`

Do not imply that 33.8% means 33.8% of Filipinos oppose ube globalization. It describes the analyzed comment dataset.

## Topic-cluster instructions

Use `editor guide/03_topic_clusters/00_cluster_map.png` briefly as the map of all seven clusters. Do not leave it on screen long enough for viewers to read every label. Cut from the map into the named cluster folder for the current narration.

The seven folders are:

1. `01_appreciation`: positive global engagement and empathy.
2. `02_pronunciation`: corrections about how “ube” is pronounced.
3. `03_ube_vs_taro`: culinary boundaries and substitution concerns.
4. `04_oob_backlash`: more emotional or meme-driven pronunciation backlash.
5. `05_matcha_fication`: comparisons with matcha, commercialization, and cultural-credit anxiety.
6. `06_agriculture_and_economy`: farmers, prices, supply, government support, and who benefits.
7. `07_botanical_accuracy`: clarifications about ube as a purple yam rather than a purple sweet potato or taro.

The script focuses on the strongest connections between these clusters. The folder structure lets the edit show more evidence without making the audience read a dense chart.

## Layering recipe for vertical video

Assume a 9:16 frame. Keep the speaker or relevant footage visible underneath the comments.

For a normal beat:

1. Place one primary comment in a large, readable card.
2. Hold it for roughly two to three seconds.
3. Add two or three smaller supporting cards around it, or cut them in one after another.
4. Keep the primary comment on screen until the viewer can finish reading it.
5. Switch to `supporting.pdf` only when the narration has room for more examples.

Do not stack five full-length comments at the same time. “More comments” should feel like a richer conversation, not a wall of unreadable text.

## Identity, wording, and safety

- Crop or blur usernames and profile photos unless permission has been obtained.
- Preserve the meaning of the source comment. Lightly censor profanity on the visual card where needed.
- Preserve typos when they help show the authentic comment, but do not draw attention to the commenter.
- Show positive appreciation alongside criticism.
- Say “comments in our dataset” or “many commenters,” not “Filipinos believe” or “Filipinos reject.”
- Say “the model classified comments as...” for the sentiment percentages.
- Attribute terms such as gentrification, appropriation, or cultural erasure to commenters or to the analysis.
- Do not present taro as a bad ingredient. The concern is substitution or mislabeling when taro is presented as authentic ube.

## If CJ runs long

Keep these findings in this order:

1. The sentiment balance and the reminder that the percentages describe this dataset.
2. Positive appreciation is genuine.
3. Pronunciation becomes a test of respect.
4. Ube, taro, and purple sweet potato are treated as distinct.
5. Recognition connects to farmers, prices, supply, and the matcha comparison.
6. Appreciation is paired with recognition and responsibility.

First remove the optional 82.7% sentence. Then remove supporting comments, not the primary comments. If more time must be cut, keep the farmer and matcha examples visible as on-screen evidence while the narration continues.

## Minimum viable edit

If editing time is limited, use only:

1. `editor guide/02_sentiment/sentiment_distribution.png`.
2. One positive comment from `01_research_overview/must_show.pdf`.
3. One pronunciation comment from `02_pronunciation/must_show.pdf`.
4. The three-label ube/taro comparison with `03_ube_vs_taro/must_show.pdf`.
5. One agriculture or price comment from `06_agriculture_and_economy/must_show.pdf`.
6. The final balanced collage from `04_synthesis/must_show.pdf`.

That shorter version still preserves the complete argument: appreciation is present, but recognition and responsibility shape how that appreciation is received.
